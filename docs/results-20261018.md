# Same-Configuration Results

## Configuration

- Protein: `7WUX`
- Seed: `101`
- Input MSA size: `1302`
- Token count: `1170`
- Atom count: `9094`
- Diffusion cycle: `10`
- Diffusion steps: `200`
- Samples: `1`
- Model storage: FP32
- TF32: disabled on both platforms
- Shared diffusion cache: disabled
- H100 kernels: cuequivariance
- 910C kernels: PSE/APB NPU fusion attention patches

## Results

| Route | Forward | Total |
|---|---:|---:|
| H100 native FP32, TF32 off | 116.53 s | 124.31 s |
| Ascend 910C + PSE | 368.39 s | 378.99 s |

Confidence differences of the 910C+PSE result relative to H100 were 0.266% for pLDDT, 0.095% for pTM, 0.055% for ipTM, and 0.063% for ranking score.

The 910C run used an NPU with about 29 GB of pre-existing HBM allocation. It completed, but the timing should be treated as resource-constrained. A repeat on an idle NPU is still required for a clean performance conclusion.
